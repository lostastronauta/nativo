Reglas de resolución de conflictos
  1. Acción vs. Marca: los elementos interactivos de acción y navegación usan --se-color-action (#0F69C4). La paleta institucional (#25306B, #006BB9, #EDF0F5, #FF1D3D) se reserva para identidad y superficies de marca.
  2. Error vs. Rojo institucional: los mensajes de error usan --se-color-error; el rojo institucional #FF1D3D no sustituye el token semántico de error.
  3. ClaveÚnica: se usa siempre la especificación oficial (N1); ningún token de marca puede alterarla.
  4. Foco: el anillo amarillo #FFBE5C es único y obligatorio en todos los elementos interactivos.
  5. Componentes: nunca usar valores HEX directos; usar los tokens semánticos de css/tokens.css.

Marco de Gobierno Digital de Chile

Norma Técnica de Interoperabilidad y Sitios Web

El Estado de Chile a través de la División de Gobierno Digital (Ministerio de Hacienda) establece lineamientos obligatorios para garantizar la coherencia visual, usabilidad y accesibilidad universal en todas las plataformas digitales públicas.

Principios Fundamentales del Framework Digital Gob.cl:
  • Centrado en las personas: Interfaces intuitivas, con lenguaje claro y jerarquía de información orientada a facilitar la realización de trámites ciudadanos.
  • Accesibilidad Universal (Decreto N.° 1/2015): Cumplimiento estricto del estándar internacional W3C/WAI WCAG 2.1 nivel AA. Toda la información debe ser perceptible, operable, comprensible y robusta.
  • Identidad Homogénea del Estado: Respeto a los logotipos ministeriales, paleta de colores del gobierno, botón institucional ClaveÚnica y remate de pie de página tricolor.
  • Diseño Mobile-First y Adaptable: Toda herramienta debe funcionar de forma óptima en teléfonos inteligentes, tablets y computadores de escritorio.

Estados de Interacción: Hover · Over · Roll · Focus · Active

Hover = mouse over = roll-over: el puntero está sobre el elemento (sólo dispositivos con puntero). Focus: el elemento recibe foco por teclado (:focus-visible). Active: mientras se presiona (pressed / tap). Disabled: no disponible. En móvil no existe hover: la información nunca debe depender de él. Pase el mouse o tabule sobre la columna Default para probar en vivo; las demás columnas muestran el estado fijo.

Módulo Header Institucional (Separado por Partes)

El Header institucional se ubica en components/header.html y se compone de 4 partes modulares perfectamente delimitadas para que TI pueda incorporar todo el conjunto o los submódulos específicos según requiera la aplicación.

Directrices de Gobierno Digital para Cabeceras:
  • El Header debe usar la etiqueta semántica <header role="banner">.
  • El logo institucional debe enlazar al inicio del portal y tener texto alternativo completo (alt="Superintendencia de Educación...").
  • En dispositivos móviles, la navegación debe colapsarse en un botón hamburguesa con atributos aria-expanded y aria-controls.
  • La navegación autenticada debe incluir una miga de pan (<nav class="breadcrumb" aria-label="Ruta">) y acceso claro al perfil y cierre de sesión seguro.

/* Supereduc Sidenav — sin dependencias */
function initSidenav(nav) {
  // Submenús
  nav.querySelectorAll('.se-sidenav__toggle').forEach(function (btn) {
    btn.addEventListener('click', function () {
      btn.setAttribute('aria-expanded', btn.getAttribute('aria-expanded') !== 'true');
    });
  });
  // Colapsar (sólo iconos)
  var col = nav.querySelector('[data-sidenav-collapse]');
  if (col) col.addEventListener('click', function () {
    var c = nav.classList.toggle('is-collapsed');
    col.setAttribute('aria-pressed', c);
    col.setAttribute('aria-label', c ? 'Expandir menú' : 'Colapsar menú');
  });
  // Off-canvas móvil
  var openBtn = document.querySelector('[data-sidenav-open][aria-controls="' + nav.id + '"]');
  var overlay = document.querySelector('[data-sidenav-overlay]');
  function setOpen(o) {
    nav.classList.toggle('is-open', o);
    if (overlay) overlay.classList.toggle('is-open', o);
    if (openBtn) openBtn.setAttribute('aria-expanded', o);
    if (o) { var f = nav.querySelector('a,button'); if (f) f.focus(); } else if (openBtn) openBtn.focus();
  }
  if (openBtn) openBtn.addEventListener('click', function () { setOpen(true); });
  if (overlay) overlay.addEventListener('click', function () { setOpen(false); });
  document.addEventListener('keydown', function (e) {
    if (e.key === 'Escape' && nav.classList.contains('is-open')) setOpen(false);
  });
}
document.querySelectorAll('.se-sidenav').forEach(initSidenav);
</script>

<script>
function formatRutInput(input) {
  let val = input.value.replace(/[^0-9kK]/g, '').toUpperCase();
  if (val.length > 1) {
    const cuerpo = val.slice(0, -1);
    const dv = val.slice(-1);
    const puntos = cuerpo.replace(/\B(?=(\d{3})+(?!\d))/g, '.');
    input.value = `${puntos}-${dv}`;
  } else {
    input.value = val;
  }
}
</script>
